# Security

## Reporting a vulnerability

Do not open a public GitHub issue for security-sensitive reports.

Contact the maintainer privately (GitHub: [@Hasanth-kumar](https://github.com/Hasanth-kumar)) with a description of the issue, steps to reproduce if possible, and impact. You will get a response confirming receipt; fixes are handled on a best-effort basis for this personal project.

## Secrets

Never commit `.env`, Notion tokens, API keys, WhatsApp credentials, or personal SQLite/data exports. Use `infrastructure/.env.example` as the template.
